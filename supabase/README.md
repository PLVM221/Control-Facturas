# Configurar Supabase

1. Abrir el proyecto en Supabase y ejecutar `schema.sql` desde **SQL Editor**.
2. Abrir `supabase-config.js`.
3. Completar `url` con la **Project URL**.
4. Completar `publishableKey` con la **Publishable key** o la clave pública `anon`.
5. No usar ni publicar la clave `service_role`.

Al configurar la conexión, los reportes locales existentes se subirán automáticamente y
los nuevos reportes quedarán disponibles desde cualquier equipo.
